ZKML (EuroSys 2024)

論文資訊

Chen, B.-J., Waiwitlikhit, S., Stoica, I., & Kang, D. (2024). "ZKML: An Optimizing System for ML Inference in Zero-Knowledge Proofs." EuroSys '24, Athens, Greece.

概述

ZKML 是首個能夠為現實規模機器學習模型產生 ZK-SNARK 證明的框架[1]。在此之前，所有 ZKML 相關工作僅能處理 MNIST、CIFAR-10 等小型模型。ZKML 突破性地支援：

  • 視覺模型：ResNet-18、VGG-16、MobileNet (ImageNet)
  • 語言模型：DistilGPT-2（8130 萬參數）
  • 推薦系統：Twitter 推薦演算法 MaskNet
  • 擴散模型：小型 Stable Diffusion

ZKML 透過設計優化編譯器，將 TensorFlow 模型轉換為 halo2 ZK-SNARK 電路。不同的電路設計選擇可影響效能達 24 倍，因此 ZKML 包含兩大核心組件：gadgets（低階操作的高效約束）與 optimizer（決定電路佈局的優化器）。

應用場景

ZKML 論文描述了多種 ZK-SNARK 在 ML 領域的應用[1]：

可信審計（Trustless Audits）

ML 模型日益強大且訓練於私有資料。例如 OpenAI 未公開 GPT-4 權重，Twitter 推薦系統訓練於用戶私有資料。ZK-SNARK 允許模型提供者承諾固定模型，並證明輸出確實由該模型產生，實現端到端的可信審計。

隱私生物認證（Private Biometric Authentication）

結合 ZK-SNARK 與認證感測器，可實現無信任的生物識別驗證。用戶拍攝照片後，使用 ML 模型驗證臉部是否匹配先前註冊的身份，同時保護隱私。

無信任信用評分（Trustless Credit Scores）

在區塊鏈場景中，用戶可能需要低抵押貸款。透過 ZK-SNARK 計算並驗證信用評分，借貸雙方都能確保評分計算的誠實性。

Gadgets 分類

ZKML 的 gadgets 分為四大類：

1. Shape Operations（形狀操作）

由於張量可持有對先前分配儲存格的引用，形狀操作（reshape、slice、concat）可邏輯上執行而無需分配新儲存格，因此對證明時間「免費」。

2. Arithmetic Operations（算術操作）

包含加、減、乘、除、平方等操作。ZKML 實作多種 gadgets 供優化器選擇：

名稱操作
Add(x, y)x + y
Mul(x, y)x · y
Div(x, y)⌊x/y⌋
DivRound(x, y)Round(x/y)
Square(x)x²
DotProd(x, y)x · y（向量內積）

3. Pointwise Non-linearities（逐點非線性）

激活函數如 ReLU、ELU、sigmoid、tanh。除 ReLU 外，這些函數難以用多項式約束高效近似，因此使用 lookup tables 實作。查表大小受限於電路列數，這限制了定點數表示的精度。

4. Specialized Operations（特化操作）

主要為 Softmax 所需的操作：

  • Maximum：使用多項式約束 (c-a)(c-b)=0 加上查表約束
  • Scaled Exponentiation：y = exp(x) · SF
  • Variable Division：VarDiv(a, b) = Round(b/a)，使用 limb 分解處理大數

電路優化

優化挑戰

halo2 電路可視為 2D 網格，儲存格值屬於大質數有限域 Fp。列數必須是 2 的冪次。有三種約束方式：

  1. 多項式約束（Custom Gates）：強制某行多項式為零
  2. 複製約束（Copy Constraint）：強制網格中任意兩儲存格相等
  3. 查表約束（Lookup Constraint）：強制某行儲存格模式存在於查表中
關鍵洞察

最高效的電路佈局取決於 ML 模型中的全域操作分布。例如，若只執行一次 ReLU，使用位元分解可能比查表更高效；但若執行 218 次 ReLU，查表則更有效率。

優化器演算法

ZKML 優化器執行以下流程[1]：

  1. 產生邏輯佈局：基於 ML 模型操作產生候選 gadget 選擇
  2. 產生物理佈局：變化網格大小，保持最小列數
  3. 成本估算：選擇最高效能佈局

成本估算聚焦於四項主要操作：

  • Fast Fourier Transformations (FFTs)
  • Multi-Scalar Multiplications (MSMs)
  • Lookup table 建立
  • 有限域元素運算

FFT 成本估算公式：

$$C_{\text{FFT}} = n_{\text{FFT}} \cdot t_{\text{FFT}}(k) + n'_{\text{FFT}} \cdot t_{\text{FFT}}(k')$$

其中 k 為列數 2k，k' = k + log2(dmax - 1)，dmax 為約束最大次數。

安全性

ZKML 繼承 halo2 的安全屬性[1]：

  • 零知識（Zero-Knowledge）：驗證者無法獲得除聲明真假外的資訊
  • 完備性（Completeness）：誠實證明者總能說服驗證者
  • 知識健全性（Knowledge Soundness）：證明者必須知道輸入和權重

halo2 支援兩種承諾方案：

方案Trusted Setup證明大小驗證速度
KZG需要（一次性、通用）較小較快
IPA不需要（透明）較大較慢

限制

  • 記憶體限制：最大模型（DistilGPT-2）需要 1TB RAM
  • 架構公開：模型架構（非權重）需要公開
  • 固定輸入長度：NLP 模型需要固定長度輸入
  • 不支援分支/迴圈：分支和迴圈會被展開
