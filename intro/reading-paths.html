推薦閱讀路徑

如何使用本知識庫

根據您的背景和目標，我們提供不同的學習路徑。選擇最適合您的路線開始探索。

路徑一：快速入門

目標讀者：想快速了解 ZKML 是什麼的讀者

預計時間：30 分鐘

  1. 總覽：什麼是 ZKML - 核心概念介紹
  2. 問題定義與場景 - ZKML 解決什麼問題
  3. 框架橫向比較 - 現有工具概覽

路徑二：密碼學背景者

目標讀者：有密碼學/ZKP 基礎，想了解 ML 整合的讀者

預計時間：2-3 小時

  1. ZKML 總覽 - 整體技術架構
  2. 模型 → 電路 - ML 到 ZKP 的轉換
  3. ZK 專用量化 - 數值處理細節
  4. 查表優化 - 非線性函數處理
  5. 量化與 Soundness - 安全性分析

路徑三：ML 背景者

目標讀者：有 ML 基礎，想了解 ZKP 驗證的讀者

預計時間：3-4 小時

  1. ZKP 基礎概念 - 零知識證明入門
  2. 完備性、可靠性、零知識 - 核心性質
  3. R1CS - 電路表示基礎
  4. 定點數與精度 - 數值表示
  5. EZKL - 實用工具入門

路徑四：區塊鏈開發者

目標讀者：想在智能合約中使用 AI 的開發者

預計時間：2-3 小時

  1. 可驗證推理 - 核心範式
  2. 區塊鏈可驗證 AI - 應用場景
  3. ZK Rollup / L2 決策 - L2 整合
  4. EZKL - 部署工具
  5. Groth16 - 鏈上驗證效率

路徑五：研究者/深度學習

目標讀者：想深入理解 ZKML 理論的研究者

預計時間：8-10 小時

第一階段：密碼學基礎

  1. 密碼學總覽
  2. KZG 多項式承諾
  3. IPA 內積論證
  4. FRI

第二階段：算術化

  1. R1CS
  2. PLONKish / AIR

第三階段：證明系統

  1. Groth16
  2. Halo2
  3. STARK

第四階段：ZKML 專題

  1. ZK 專用量化
  2. 配置空間與調參
  3. ZK 成本指標
  4. ZKML (EuroSys 2024)
  5. ZKTorch

路徑六：論文導向

目標讀者：想理解本論文貢獻的讀者

  1. 論文概覽
  2. Cost Function 設計 - 核心貢獻
  3. 配置空間與調參
  4. 框架橫向比較
