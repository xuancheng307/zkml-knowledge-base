Transformer 架構

LLM 的基礎

Transformer 是現代大型語言模型的核心架構。理解其組件對 ZKML 處理 LLM 至關重要。

核心組件

Self-Attention

計算：
  Attention(Q, K, V) = softmax(QK^T / √d_k) · V

ZKML 挑戰：
  - 矩陣乘法：O(n² · d) 約束
  - Softmax：每行需要特殊處理
  - 記憶體：O(n²) 中間值

zkLLM 的 zkAttn 優化：
  使用 tlookup 減少複雜度

Feed-Forward Network

結構：
  FFN(x) = GELU(xW₁ + b₁)W₂ + b₂

ZKML 考量：
  - 兩個大型矩陣乘法
  - GELU 需要查表處理
  - 隱藏層通常是輸入的 4 倍

LayerNorm

計算：
  LayerNorm(x) = (x - μ) / σ · γ + β

ZKML 挑戰：
  - 需要計算均值和標準差
  - 除法和開根號
  - 通常使用近似
