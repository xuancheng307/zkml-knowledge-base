FRI 多項式承諾

核心概念

FRI（Fast Reed-Solomon Interactive Oracle Proof of Proximity）是一種基於雜湊函數的多項式承諾方案，是 STARK 證明系統的核心組件[1]。FRI 不需要可信設置，且具備後量子安全性，但證明大小較大。

形式化定義

Definition 1：Reed-Solomon 編碼

給定有限域 \(\mathbb{F}\)、求值域 \(D \subset \mathbb{F}\)（\(|D| = n\)）和次數界限 \(d < n\)，Reed-Solomon 編碼定義為：

\[\text{RS}[\mathbb{F}, D, d] := \{(f(\omega^0), f(\omega^1), \ldots, f(\omega^{n-1})) : f \in \mathbb{F}[X], \deg(f) < d\}\]

其中 \(\omega\) 是 \(D\) 作為乘法子群的生成元。碼率為 \(\rho = d/n\)。

Definition 2：相對 Hamming 距離

兩個向量 \(\mathbf{u}, \mathbf{v} \in \mathbb{F}^n\) 的相對 Hamming 距離定義為：

\[\Delta(\mathbf{u}, \mathbf{v}) := \frac{|\{i : u_i \neq v_i\}|}{n}\]

向量 \(\mathbf{u}\) 到碼 \(C\) 的距離定義為：\(\Delta(\mathbf{u}, C) := \min_{\mathbf{c} \in C} \Delta(\mathbf{u}, \mathbf{c})\)

Definition 3：\(\delta\)-接近性（\(\delta\)-Closeness）

函數 \(f: D \to \mathbb{F}\) 被稱為與 \(\text{RS}[\mathbb{F}, D, d]\) \(\delta\)-接近，若且唯若：

\[\exists p \in \mathbb{F}[X], \deg(p) < d : \Delta(f, p|_D) \leq \delta\]

其中 \(p|_D\) 表示 \(p\) 在 \(D\) 上的求值向量。

Definition 4：Interactive Oracle Proof of Proximity (IOPP)

IOPP 是一個 IOP 協議，用於判定問題 \((C, \delta)\)-proximity：

  • 完備性：若 \(\mathbf{u} \in C\)，誠實證明者總能使驗證者接受
  • Soundness：若 \(\Delta(\mathbf{u}, C) > \delta\)，則對任意證明策略，驗證者以高機率拒絕
Definition 5：Blow-up Factor（膨脹因子）

FRI 協議中的膨脹因子定義為：

\[\rho^{-1} = \frac{|D|}{d} = \frac{n}{d}\]

常見選擇為 \(\rho^{-1} \in \{2, 4, 8, 16\}\)。膨脹因子越大，soundness 越好但證明者工作量增加。

Definition 6：Coset（陪集）結構

設 \(D = \langle \omega \rangle\) 是 \(\mathbb{F}^*\) 的乘法子群，定義：

  • 二次剩餘子群：\(D^{(1)} = \{x^2 : x \in D\} = \langle \omega^2 \rangle\)
  • 陪集分解：\(D = D^{(1)} \cup \omega \cdot D^{(1)}\)（對 \(\pm\omega^i\) 配對）

此結構使得折疊後的域大小減半。

Definition 7：Merkle 承諾

對向量 \(\mathbf{v} = (v_0, \ldots, v_{n-1})\)，Merkle 樹承諾定義為：

\[\text{MT.Commit}(\mathbf{v}) := \text{root}(\text{BuildTree}(\{H(v_i)\}_{i=0}^{n-1}))\]

其中 \(H\) 是抗碰撞雜湊函數，開啟證明大小為 \(O(\log n)\) 個雜湊值。

核心思想

Reed-Solomon 編碼

FRI 利用 Reed-Solomon 碼的數學性質[1]：

  • 次數 \(d\) 的多項式可由 \(d+1\) 個點唯一確定
  • 若函數 \(f: D \to \mathbb{F}\) 是次數 \(\leq d\) 的多項式，則其在任意子集上的限制也具有此性質
  • 若 \(f\) 不是低次多項式，則它與任何低次多項式有顯著距離

接近性測試

FRI 的目標是證明[1]：

給定對函數 \(f: D \to \mathbb{F}\) 的預言機存取，
\(f\) 與某個次數 \(\leq d\) 的多項式 \(\delta\)-接近。

其中 \(\delta\)-接近表示：\(|\{x \in D : f(x) \neq p(x)\}| < \delta |D|\)

FRI 協議

協議概覽

FRI 協議分為兩個階段[1]：

  1. 承諾階段（Commit Phase）：證明者透過迭代折疊將多項式次數減半
  2. 查詢階段（Query Phase）：驗證者抽樣檢查折疊的一致性

Algorithm 1：FRI.Commit

FRI.Commit(f, D, ρ):
  輸入：
    - f ∈ F[X]：次數 < d 的多項式
    - D ⊂ F：求值域，|D| = n = d/ρ（乘法子群）
    - ρ：碼率（rate）

  輸出：
    - (C₀, C₁, ..., Cₖ)：各層 Merkle root
    - f_final：最終常數值
    - transcript：Fiat-Shamir 轉錄

  1. 初始化：
     f⁽⁰⁾ := f
     D⁽⁰⁾ := D
     k := log₂(d)  // 折疊輪數
     transcript := ∅

  2. 對整個域求值並承諾：
     評估向量 v⁽⁰⁾ := (f⁽⁰⁾(ω⁰), f⁽⁰⁾(ω¹), ..., f⁽⁰⁾(ω^{n-1}))
     C₀ := MT.Commit(v⁽⁰⁾)
     transcript := transcript || C₀

  3. 迭代折疊（i = 1 to k）：
     a. 生成隨機挑戰：
        αᵢ := H(transcript)  // Fiat-Shamir

     b. 計算折疊多項式：
        對 f⁽ⁱ⁻¹⁾(X) = f_even(X²) + X · f_odd(X²)
        f⁽ⁱ⁾(Y) := f_even(Y) + αᵢ · f_odd(Y)

     c. 更新求值域：
        D⁽ⁱ⁾ := {x² : x ∈ D⁽ⁱ⁻¹⁾}
        注意：|D⁽ⁱ⁾| = |D⁽ⁱ⁻¹⁾|/2

     d. 求值並承諾：
        v⁽ⁱ⁾ := (f⁽ⁱ⁾(y) : y ∈ D⁽ⁱ⁾)
        Cᵢ := MT.Commit(v⁽ⁱ⁾)
        transcript := transcript || Cᵢ

  4. 最終層：
     f_final := f⁽ᵏ⁾（常數多項式）

  return (C₀, ..., Cₖ, f_final, transcript)

Algorithm 2：FRI.Query

FRI.Query(commitments, transcript, λ):
  輸入：
    - commitments = (C₀, ..., Cₖ)：各層承諾
    - transcript：之前的轉錄
    - λ：安全參數（查詢次數）

  輸出：
    - queries：λ 個查詢及其 Merkle 證明

  1. 生成查詢點：
     for q = 1 to λ:
       // 使用 Fiat-Shamir 生成隨機起始點
       s_q := H(transcript || q) mod |D⁽⁰⁾|
       x₀⁽ᑫ⁾ := ω^{s_q}  // D⁽⁰⁾ 中的點

  2. 對每個查詢收集路徑：
     for q = 1 to λ:
       path_q := []
       x := x₀⁽ᑫ⁾

       for i = 0 to k-1:
         // 查詢點及其「配對點」
         x⁺ := x
         x⁻ := -x  // 在乘法群中，-ω^j = ω^{j+n/2}

         // 獲取值和 Merkle 證明
         (v⁺, π⁺) := MT.Open(Cᵢ, x⁺)
         (v⁻, π⁻) := MT.Open(Cᵢ, x⁻)

         path_q.append((v⁺, v⁻, π⁺, π⁻))

         // 移動到下一層
         x := x²  // 對應 D⁽ⁱ⁺¹⁾ 中的點

       queries.append((x₀⁽ᑫ⁾, path_q))

  return queries

Algorithm 3：FRI.Verify

FRI.Verify(commitments, f_final, queries, transcript):
  輸入：
    - commitments = (C₀, ..., Cₖ)
    - f_final：聲稱的最終常數
    - queries：λ 個查詢路徑
    - transcript：Fiat-Shamir 轉錄

  輸出：
    - accept/reject

  1. 重建隨機挑戰：
     for i = 1 to k:
       αᵢ := H(transcript 前綴到 Cᵢ₋₁)

  2. 對每個查詢驗證：
     for q = 1 to λ:
       (x₀, path) := queries[q]
       x := x₀

       for i = 0 to k-1:
         (v⁺, v⁻, π⁺, π⁻) := path[i]

         // 步驟 2a：驗證 Merkle 證明
         if not MT.Verify(Cᵢ, x, v⁺, π⁺):
           return reject
         if not MT.Verify(Cᵢ, -x, v⁻, π⁻):
           return reject

         // 步驟 2b：驗證折疊一致性
         // f(x) = f_even(x²) + x · f_odd(x²)
         // f(-x) = f_even(x²) - x · f_odd(x²)
         // 因此：
         //   f_even(x²) = (f(x) + f(-x)) / 2
         //   f_odd(x²) = (f(x) - f(-x)) / (2x)
         // 折疊值：f'(x²) = f_even(x²) + α · f_odd(x²)

         v_even := (v⁺ + v⁻) / 2
         v_odd := (v⁺ - v⁻) / (2 · x)
         expected := v_even + αᵢ₊₁ · v_odd

         // 獲取下一層在 x² 處的值
         if i < k-1:
           actual := path[i+1].v⁺ 或 v⁻（取決於 x² 的位置）
         else:
           actual := f_final

         if expected ≠ actual:
           return reject

         x := x²

  return accept

Reed-Solomon 折疊

折疊的數學基礎

FRI 的核心是多項式折疊操作[1]。給定多項式 \(f(X)\)，可唯一分解為：

\[f(X) = f_{\text{even}}(X^2) + X \cdot f_{\text{odd}}(X^2)\]

其中：

  • \(f_{\text{even}}(Y) = \sum_{i=0}^{d/2-1} c_{2i} \cdot Y^i\)（偶數係數）
  • \(f_{\text{odd}}(Y) = \sum_{i=0}^{d/2-1} c_{2i+1} \cdot Y^i\)（奇數係數）

折疊算子

FRI.Fold(f, α):
  輸入：
    - f(X) = Σᵢ cᵢXⁱ：次數 < d 的多項式
    - α ∈ F：隨機折疊因子

  輸出：
    - f'(Y)：次數 < d/2 的多項式

  1. 分解 f：
     f_even(Y) := c₀ + c₂Y + c₄Y² + ...
     f_odd(Y) := c₁ + c₃Y + c₅Y² + ...

  2. 線性組合：
     f'(Y) := f_even(Y) + α · f_odd(Y)

  3. 次數保證：
     deg(f') ≤ max(deg(f_even), deg(f_odd))
            = ⌊deg(f)/2⌋

  範例：
    f(X) = 3 + 5X + 7X² + 2X³ + X⁴（deg = 4）
    f_even(Y) = 3 + 7Y + Y²
    f_odd(Y) = 5 + 2Y

    取 α = 4：
    f'(Y) = (3 + 7Y + Y²) + 4·(5 + 2Y)
          = 23 + 15Y + Y²（deg = 2）

折疊與求值的關係

關鍵觀察：給定 \(f(x)\) 和 \(f(-x)\)，可以在不知道多項式係數的情況下計算折疊值[1]：

從求值計算折疊：
  已知：
    f(x) = f_even(x²) + x · f_odd(x²)
    f(-x) = f_even(x²) - x · f_odd(x²)

  求解：
    f_even(x²) = [f(x) + f(-x)] / 2
    f_odd(x²) = [f(x) - f(-x)] / (2x)

  折疊值：
    f'(x²) = f_even(x²) + α · f_odd(x²)
           = [f(x) + f(-x)]/2 + α · [f(x) - f(-x)]/(2x)
           = [(1 + α/x)·f(x) + (1 - α/x)·f(-x)] / 2

數值範例：
  設 f(X) = 2 + 3X + X²（在 F₁₇ 上）
  取 x = 4，則 -x = 13（在 F₁₇ 中）

  f(4) = 2 + 12 + 16 = 30 ≡ 13 (mod 17)
  f(13) = 2 + 39 + 169 = 210 ≡ 6 (mod 17)

  f_even(16) = (13 + 6)/2 = 19/2 ≡ 19·9 ≡ 1 (mod 17)
  f_odd(16) = (13 - 6)/(2·4) = 7/8 ≡ 7·15 ≡ 3 (mod 17)

  取 α = 5：
  f'(16) = 1 + 5·3 = 16

折疊正確性定理

Theorem 1：折疊保持低次性

設 \(f \in \mathbb{F}[X]\) 滿足 \(\deg(f) < d\)，\(\alpha \in \mathbb{F}\) 為任意域元素。則折疊結果 \(f' = \text{Fold}(f, \alpha)\) 滿足 \(\deg(f') < d/2\)。

證明：由定義，\(f_{\text{even}}\) 和 \(f_{\text{odd}}\) 的次數均 \(\leq \lfloor(d-1)/2\rfloor < d/2\)。線性組合不增加次數。∎

Theorem 2：折疊的可驗證性

對於 \(x \in D\) 和 \(-x \in D\)（其中 \(x^2 \in D'\)），折疊值 \(f'(x^2)\) 可由 \(f(x), f(-x), \alpha\) 唯一確定。

查詢複雜度分析

複雜度總覽

操作 時間複雜度 空間複雜度 說明
Setup \(O(1)\) \(O(1)\) 完全透明，無需設置

查詢數量與安全性

FRI 的 soundness error 由查詢數量和碼參數決定[1]：

Theorem 3：FRI Soundness Error

設 FRI 協議使用碼率 \(\rho\)，距離參數 \(\delta\)，執行 \(\lambda\) 次獨立查詢。則 soundness error 為：

\[\epsilon_{\text{sound}} \leq \left( \max\{\rho^{1/2}, 1 - \delta + \epsilon_0\} \right)^\lambda\]

其中 \(\epsilon_0\) 是與碼距相關的小常數。

查詢數量計算：

給定目標安全等級 κ bits：
  λ ≥ κ / log₂(1 / max{ρ^{1/2}, 1-δ+ε})

範例配置（ρ = 1/4，即 4x blowup）：
  - 每次查詢貢獻 ≈ 2 bits 安全性
  - 80-bit 安全：λ ≈ 40 次查詢
  - 128-bit 安全：λ ≈ 64 次查詢

範例配置（ρ = 1/8，即 8x blowup）：
  - 每次查詢貢獻 ≈ 2.5 bits 安全性
  - 80-bit 安全：λ ≈ 32 次查詢
  - 128-bit 安全：λ ≈ 52 次查詢

證明大小分析

證明大小 = 承諾 + 查詢路徑 + 最終值

詳細分解：
  1. 承諾階段：
     - k = log₂(d) 個 Merkle root
     - 每個 root: 32 bytes（256-bit hash）
     - 總計：32k bytes

  2. 查詢階段（每次查詢）：
     - k 層，每層 2 個葉節點值
     - 每層 2 條 Merkle 路徑，每條 log₂(n/2^i) 個雜湊
     - 單次查詢：≈ 2k · (log₂(n) + log₂(n/2) + ... + 1) / k
                ≈ 2k · log₂(n) 雜湊 = 64k log₂(n) bytes

  3. λ 次查詢總計：
     - 64 · λ · k · log₂(n) bytes（可優化）

  4. 最終常數值：O(1) bytes

總證明大小（未優化）：
  O(λ · log²(n)) bytes

數值範例（n = 2²⁰，λ = 64，k = 20）：
  ≈ 64 × 20 × 20 × 32 = 819,200 bytes ≈ 800 KB

優化後（使用 Merkle cap）：
  ≈ 80-150 KB（減少 80-90%）

Soundness 分析

Soundness 直觀理解

FRI 的 soundness 來自兩個關鍵觀察[1]：

  1. 距離放大：若 \(f\) 遠離低次多項式，折疊後距離不會減少太多
  2. 局部一致性：惡意證明者無法同時欺騙所有查詢點

Johnson Bound

Definition 8：Johnson Bound

對於 \([n, k, d]_q\) Reed-Solomon 碼（碼長 \(n\)，維度 \(k\)，最小距離 \(d = n - k + 1\)），Johnson 半徑定義為：

\[\delta_J := 1 - \sqrt{\rho} = 1 - \sqrt{k/n}\]

在此半徑內，任意點的鄰居數有界。

Correlated Agreement 定理

Theorem 4：Correlated Agreement

設 \(f^{(0)}\) 是提交的初始函數，\(f^{(1)}, \ldots, f^{(k)}\) 是折疊後的函數。若 FRI 驗證者以機率 \(\geq \epsilon\) 接受，則存在多項式 \(p^{(0)}, \ldots, p^{(k)}\) 使得：

  1. \(\deg(p^{(i)}) < d/2^i\)（次數遞減）
  2. \(p^{(i+1)} = \text{Fold}(p^{(i)}, \alpha_i)\)（折疊一致）
  3. \(\Pr_{x \in D^{(i)}}[f^{(i)}(x) = p^{(i)}(x)] \geq 1 - \delta + \epsilon'\)（高一致性）

其中 \(\epsilon' = O(\epsilon / \lambda)\) 取決於查詢數。

Soundness 證明框架

Soundness 證明思路：

反證法：假設 f⁽⁰⁾ 距離 RS[F, D, d] 超過 δ

1. 折疊分析：
   - 每次折疊，若 f⁽ⁱ⁾ 遠離 RS[F, D⁽ⁱ⁾, d/2ⁱ]
   - 則 f⁽ⁱ⁺¹⁾ 以高機率仍遠離 RS[F, D⁽ⁱ⁺¹⁾, d/2^{i+1}]

2. 距離衰減引理：
   Δ(f⁽ⁱ⁺¹⁾, RS) ≥ g(Δ(f⁽ⁱ⁾, RS))
   其中 g 是某個漸進衰減函數

3. 查詢檢測：
   - 單次查詢檢測到不一致的機率 ≥ Δ(f⁽ⁱ⁾, RS)
   - λ 次獨立查詢後，全部逃過的機率 ≤ (1 - Δ)^λ

4. 結合各層：
   - 總 soundness error = Π_i (1 - Δᵢ)^λ
   - 由距離衰減引理，這被 (max{ρ^{1/2}, 1-δ})^λ 控制

完備性證明

Theorem 5：FRI 完備性

若 \(f \in \text{RS}[\mathbb{F}, D, d]\)（即 \(f\) 是次數 \(< d\) 的多項式在 \(D\) 上的求值），則誠實證明者產生的證明總是被驗證者接受。

證明：

  1. 由 Theorem 1，每次折疊保持低次性：\(\deg(f^{(i)}) < d/2^i\)
  2. 折疊公式的代數正確性確保一致性檢查通過
  3. Merkle 證明由誠實構建，必定正確
  4. 因此驗證者總是接受。∎

DEEP-FRI 變體

DEEP（Domain Extension for Elimination of Preprocessing）是 FRI 的重要改進[2]，透過在域外採樣增強 soundness。

DEEP-FRI 動機

標準 FRI 的限制：

  • soundness 依賴 Johnson bound，需要較大 blowup factor
  • 對某些「壞」函數，可能需要更多查詢
  • 批次開啟多個多項式時效率不佳

DEEP-FRI 協議

DEEP-FRI.Prove(f, D, z):
  輸入：
    - f：待證明的多項式
    - D：求值域
    - z ∉ D：域外隨機點（由 Fiat-Shamir 生成）

  1. 計算域外求值：
     y := f(z)
     證明者發送 y

  2. 構造商多項式：
     g(X) := [f(X) - y] / (X - z)

     關鍵性質：
     - 若 f 是次數 < d 的多項式，則 g 是次數 < d-1 的多項式
     - 若 f 在某些點「作弊」，則 g 在那些點會產生非多項式值

  3. 對 g 執行標準 FRI：
     FRI.Prove(g, D)

DEEP-FRI.Verify(commitments, y, z, proof):
  1. 驗證商多項式的 FRI 證明
  2. 對每個查詢點 x，檢查：
     f(x) = g(x) · (x - z) + y

優勢分析：
  - 域外採樣消除了 Johnson bound 的依賴
  - 2x blowup 即可達到與標準 FRI 4x blowup 相同的安全性
  - 證明大小減少 ~40-50%

批次多項式開啟

批次 DEEP-FRI：同時開啟 f₁, f₂, ..., fₘ 在點 z

1. 證明者發送各 yᵢ = fᵢ(z)

2. 驗證者發送隨機線性組合係數 β₁, ..., βₘ

3. 構造組合多項式：
   F(X) := Σᵢ βᵢ · fᵢ(X)
   Y := Σᵢ βᵢ · yᵢ

4. 對商多項式執行 FRI：
   G(X) := [F(X) - Y] / (X - z)

效率：
  - m 個多項式只需一次 FRI 證明
  - 額外開銷：m 個域元素（各 yᵢ）

安全性證明

安全假設

FRI 僅依賴以下加密假設：

Definition 9：抗碰撞雜湊函數（CRHF）

函數 \(H: \{0,1\}^* \to \{0,1\}^\kappa\) 是抗碰撞的，若對於所有 PPT 敵手 \(\mathcal{A}\)：

\[\Pr[(x, x') \leftarrow \mathcal{A}(1^\kappa) : x \neq x' \land H(x) = H(x')] \leq \text{negl}(\kappa)\]

Definition 10：隨機預言機（Random Oracle）

在隨機預言機模型中，雜湊函數 \(H\) 被建模為一個理想化的隨機函數。Fiat-Shamir 變換在此模型下將互動協議轉換為非互動協議。

Theorem 6：FRI 安全性定理

Theorem 6：FRI IOP 安全性

在隨機預言機模型中，FRI 是一個安全的 RS-IOPP：

  • 完備性：完美（\(\epsilon_c = 0\)）
  • Soundness：\(\epsilon_s \leq (\max\{\sqrt{\rho}, 1-\delta\})^\lambda + q_H \cdot 2^{-\kappa}\)
  • 知識提取：存在 PPT 提取器可從接受的證明重構多項式

其中 \(q_H\) 是敵手的雜湊查詢數，\(\kappa\) 是雜湊輸出長度。

後量子安全性分析

FRI 的後量子安全性：

1. 雜湊函數安全性：
   - 經典：SHA-256 提供 256-bit 碰撞抗性
   - 量子：Grover 算法將碰撞抗性降至 128-bit
   - 解決：使用 SHA-512 或更長雜湊

2. Fiat-Shamir 安全性：
   - 在量子隨機預言機模型（QROM）中仍然安全
   - 需要增加查詢數以補償

3. 參數調整：
   - 雜湊長度：256 → 512 bits
   - 查詢數：保持或略增
   - 證明大小增加：~1.5-2x

4. 與基於群的方案比較：

   │ 方案         │ 經典安全       │ 後量子安全    │
