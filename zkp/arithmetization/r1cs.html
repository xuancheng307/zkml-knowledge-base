R1CS 算術化

核心概念

R1CS（Rank-1 Constraint System）是一種將計算問題轉換為代數約束的標準格式，廣泛用於 Groth16、PLONK 等 SNARK 系統[1]。每個約束形式為 \(\langle \mathbf{a}, \mathbf{w} \rangle \cdot \langle \mathbf{b}, \mathbf{w} \rangle = \langle \mathbf{c}, \mathbf{w} \rangle\)。

R1CS 定義

形式化定義

一個 R1CS 實例由以下組成[1]：

R1CS = (F, A, B, C, m, n, l)

其中：
  F：有限域（通常是大質數域）
  A, B, C：m × n 矩陣，元素在 F 上
  m：約束數量
  n：見證向量長度（包含常數項）
  l：公開輸入數量

見證向量 w ∈ F^n，使用 0-based 索引：
  w = (w₀, w₁, ..., w_{n-1})

結構劃分：
  w₀ = 1              ← 常數項（固定為 1）
  w₁, ..., w_l        ← 公開輸入（共 l 個，索引 1..l）
  w_{l+1}, ..., w_{n-1}  ← 私密見證（共 n-l-1 個）

維度一致性：
  - w 的長度 = n（索引範圍：0 到 n-1）
  - A, B, C 的列數 = n（與 w 維度匹配）
  - 內積 ⟨A_i, w⟩ 在維度上成立：A_i ∈ F^n, w ∈ F^n

範例（n=5, l=2）：
  w = (1, x₁, x₂, w₃, w₄)
       ↑   ↑────↑  ↑────↑
     常數  公開輸入  私密見證

約束滿足

向量 \(\mathbf{w}\) 滿足 R1CS 當且僅當對所有 \(i \in [m]\)[1]：

$$(A \mathbf{w})_i \cdot (B \mathbf{w})_i = (C \mathbf{w})_i$$

等價於：

$$(A \mathbf{w}) \circ (B \mathbf{w}) = C \mathbf{w}$$

其中 \(\circ\) 表示 Hadamard（逐元素）乘積。

從計算到 R1CS

基本門電路

常見運算的 R1CS 表示[2]：

1. 乘法門：z = x · y
   約束：x · y = z
   A = [0, 1, 0, 0]  // 選取 x
   B = [0, 0, 1, 0]  // 選取 y
   C = [0, 0, 0, 1]  // 選取 z
   向量 w = [1, x, y, z]

2. 加法門：z = x + y（不需要約束！）
   加法是線性的，可直接在向量中表示
   若需約束：1 · (x + y) = z
   A = [0, 1, 1, 0]
   B = [1, 0, 0, 0]  // 選取常數 1
   C = [0, 0, 0, 1]

3. 常數乘法：z = c · x（同樣是線性的）
   向量 w = [1, x, z]
   若需約束：c · x · 1 = z
   A = [0, c, 0]  // 選取 c·x
   B = [1, 0, 0]  // 選取常數 1
   C = [0, 0, 1]  // 選取 z
   驗證：(A·w)(B·w) = (c·x)·1 = c·x = z = C·w ✓

複雜表達式

表達式：z = (x + y) · (x - y)

展開為中間變數：
  t₁ = x + y
  t₂ = x - y
  z = t₁ · t₂

只需一個乘法約束：
  (x + y) · (x - y) = z

R1CS 表示（w = [1, x, y, z]）：
  A = [0, 1, 1, 0]   // x + y
  B = [0, 1, -1, 0]  // x - y
  C = [0, 0, 0, 1]   // z

布林約束

強制變數為布林值（0 或 1）：
  b · (1 - b) = 0

R1CS 表示（w = [1, b]）：
  A = [0, 1]   // b
  B = [1, -1]  // 1 - b
  C = [0, 0]   // 0

若 b ∉ {0, 1}，則 b · (1-b) ≠ 0

ZKML 中的 R1CS

神經網路層

矩陣乘法的 R1CS 表示[3]：

線性層：y = Wx + b
其中 W ∈ F^{m×n}，x ∈ F^n，b ∈ F^m

R1CS 編碼：
  對於每個輸出 y_i = Σ_j W_{ij} · x_j + b_i

  因為這是線性的，可以合併到其他乘法中
  或使用單一約束：
  1 · (Σ W_{ij} · x_j + b_i) = y_i

約束數量：O(m)（每個輸出一個）
變數數量：O(n + m)

激活函數

ReLU：y = max(0, x)

標準 R1CS 無法直接表示比較
需要分解：

方法 1：位元分解
  x = Σ_{i=0}^{k-1} 2^i · b_i
  每個 b_i 是布林（k 個約束）
  符號位決定 ReLU 輸出

方法 2：輔助變數
  引入 s ∈ {0, 1}：符號指示器
  y = s · x（若 s=1 則正，若 s=0 則零）
  需要額外約束確保一致性

約束數量：O(log |F|) 每個 ReLU

查表優化

ZKML 系統常用查表替代複雜約束[3]：

查表約束（需要 PLONKish 擴展）：
  驗證 (x, y) 在預定義表格 T 中

ReLU 查表：
  T = {(i, max(0, i)) : i ∈ [-2^k, 2^k]}
  約束：(x, y) ∈ T

優勢：
  - O(1) 約束而非 O(log |F|)
  - 適用於任何非線性函數

代價：
  - 需要 PLONKish 算術化
  - 表格大小影響證明效率

R1CS 優化

約束壓縮

技術 1：線性組合
  多個線性關係可合併
  a + b = c 和 c + d = e
  → a + b + d = e（減少一個約束）

技術 2：共享中間變數
  若 t 在多處使用，只計算一次

技術 3：延遲計算
  將多個乘法鏈合併
  z = a·b·c·d 需要 3 個約束
  但可透過巧妙組織減少

稀疏矩陣表示

實務中，A, B, C 極為稀疏

稀疏表示：
  A[i] = [(j₁, a₁), (j₂, a₂), ...]

好處：
  - 儲存：O(非零元素數) 而非 O(m·n)
  - 計算：稀疏矩陣乘法更快

ZKML 特性：
  - 神經網路權重通常稀疏（剪枝後）
  - 可利用結構化稀疏模式

R1CS 到多項式

QAP 轉換

Quadratic Arithmetic Program 是 R1CS 的多項式表示[1]：

轉換步驟：
  1. 選取 m 個不同的域元素 r₁, ..., r_m

  2. 對每列 j，插值得到多項式：
     a_j(X)：通過點 (r_i, A_{ij})
     b_j(X)：通過點 (r_i, B_{ij})
     c_j(X)：通過點 (r_i, C_{ij})

  3. 定義：
     A(X) = Σ w_j · a_j(X)
     B(X) = Σ w_j · b_j(X)
     C(X) = Σ w_j · c_j(X)

  4. R1CS 滿足 ⟺ A(X)·B(X) - C(X) 被 Z(X) = Π(X - r_i) 整除

QAP 關係：
  ∃ H(X): A(X)·B(X) - C(X) = H(X)·Z(X)

PLONK 轉換

PLONK 使用不同的多項式編碼[4]：

PLONK 約束形式：
  q_L·a + q_R·b + q_O·c + q_M·a·b + q_C = 0

從 R1CS 約束 (a·b = c) 轉換：
  q_L = 0, q_R = 0, q_O = -1, q_M = 1, q_C = 0
  → 0·a + 0·b + (-1)·c + 1·(a·b) + 0 = 0
  → a·b = c ✓

PLONK 優勢：
  - 通用參考字串（一次設置，多次使用）
  - 更靈活的約束組合

複雜度分析

操作 R1CS 複雜度 說明
乘法 1 約束 基本單位
加法 0 約束 線性，無需約束
ReLU（位元分解） O(log |F|) 約束 ~254 約束（BN254）
ReLU（查表） O(1) 約束 需要 PLONKish
矩陣乘法 (m×n) O(m·n) 約束 每個乘法一個約束
卷積 (k×k, c_in, c_out) O(k²·c_in·c_out·H·W) 展開為矩陣乘法

ZKML 框架處理

EZKL 流程：
  1. 讀取 ONNX 模型
  2. 自動生成 R1CS/PLONKish 約束
  3. 優化激活函數（使用查表）
  4. 產生 Halo2 電路

ZKTorch 流程：
  1. PyTorch 模型編譯
  2. 算術化選擇（R1CS 或 PLONKish）
  3. 自動配置查表範圍
  4. 生成證明

與 PLONKish 的比較

特性 R1CS PLONKish
約束形式 \(a \cdot b = c\) 自定義門 + 查表
靈活性 較低 高（可定義任意門）
非線性處理 位元分解（昂貴） 查表（高效）
設置 電路特定 通用（或透明）
代表系統 Groth16 PLONK, Halo2
ZKML 適用性 基礎架構 更適合（查表優勢）
