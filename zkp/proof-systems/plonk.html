PLONK

核心概念

PLONK（Permutations over Lagrange-bases for Oecumenical Noninteractive arguments of Knowledge）是一種通用零知識 SNARK 協議，由 Gabizon、Williamson 和 Ciobotaru 於 2019 年提出[1]。PLONK 使用 Lagrange 基底算術化和置換論證，實現了通用可信設置，成為現代 ZKML 系統的核心證明系統。

背景與動機

問題背景

在 PLONK 之前，主流的 zk-SNARK 系統面臨以下限制：

系統 主要限制 影響
Groth16 電路特定設置（Circuit-specific Setup） 每個電路都需要獨立的可信設置儀式
Sonic 通用但效率較低 證明者效率不如 Groth16
定義：通用可信設置（Universal Trusted Setup）

一種結構化參考字串（SRS）生成方式，其中 SRS 可以被多個不同的電路重複使用，只要電路大小不超過預設的上界 \(d\)。與電路特定設置相比，通用設置只需執行一次，大幅降低部署成本。

PLONK 的創新

PLONK 的核心貢獻：

1. 通用性
   - 一次設置，多次使用
   - 不需為每個電路重新進行 MPC 儀式

2. 高效證明者
   - 基於 Lagrange 基底的多項式運算
   - 利用 FFT 加速
   - 效率接近 Groth16

3. 置換論證
   - 優雅處理複製約束
   - Grand Product 累積器技術

4. 可擴展性
   - 支援自定義門（Custom Gates）
   - 支援查表（Plookup）
   - 遞迴證明友好

安全假設

定義：代數群模型（Algebraic Group Model, AGM）

AGM 假設對手只能透過群運算來操作群元素[2]。在 AGM 下，對手輸出的任何群元素都必須是其接收到的群元素的線性組合。這個模型介於標準模型和通用群模型之間，提供了更強的安全保證。

PLONK 安全基礎：

1. 離散對數假設（DL）
   給定 g 和 g^x，難以計算 x

2. 知識離散對數假設（KoE）
   給定 (g, g^x)，若能輸出 (h, h^x)
   則必須「知道」某個 c 使得 h = g^c

3. AGM 下的知識健全性
   結合 AGM 和 KoE，PLONK 達成知識健全性

數學基礎

有限域與群

定義：乘法子群（Multiplicative Subgroup）

設 \(\mathbb{F}_p\) 為素數域，\(\omega\) 為 \(n\) 次單位根（即 \(\omega^n = 1\) 且 \(\omega^k \neq 1\) 對於 \(0 < k < n\)）。則乘法子群定義為：

\(H = \{1, \omega, \omega^2, \ldots, \omega^{n-1}\}\)

PLONK 選擇 \(n = 2^k\) 以利用 FFT 加速。

Lagrange 基底

Lagrange 基底多項式 L_i(X)：

定義：
  L_i(ω^j) = δ_{ij} = { 1 if i = j
                      { 0 if i ≠ j

顯式公式：
  L_i(X) = (ω^{-i} · (X^n - 1)) / (n · (X - ω^i))

特殊情況（L_0 在 X=1=ω⁰ 處為 1）：
  L_0(X) = (X^n - 1) / (n · (X - 1))

性質：
  - 任何定義在 H 上的函數 f 可表示為：
    f(X) = Σ_{i=0}^{n-1} f(ω^i) · L_i(X)

  - 用於邊界條件驗證：
    L_0(X) · (z(X) - 1) = 0 在 H 上
    ⟺ z(ω^0) = z(1) = 1

KZG 多項式承諾

定義：KZG 承諾方案[3]

KZG（Kate-Zaverucha-Goldberg）多項式承諾包含三個算法：

  • Commit(f)：計算 \([f]_1 = f(\tau) \cdot G_1\)，其中 \(\tau\) 是設置時的秘密值
  • Open(f, z)：計算商多項式 \(W_z(X) = \frac{f(X) - f(z)}{X - z}\) 並輸出 \([W_z]_1\)
  • Verify([f]_1, z, y, [W_z]_1)：檢查配對方程式
KZG 驗證方程式（τ 為 SRS trapdoor）：

e([W_z]_1, [τ - z]_2) = e([f]_1 - y·[1]_1, [1]_2)

等價形式（避免在 G_2 做減法）：
e([W_z]_1, [τ]_2) = e(z·[W_z]_1 + [f]_1 - y·[1]_1, [1]_2)

正確性證明：
  若 f(z) = y，則 W_z(X) = (f(X) - y)/(X - z) 是多項式
  左式 = e(W_z(τ)·G_1, (τ - z)·G_2)
       = e(G_1, G_2)^{W_z(τ)·(τ-z)}
       = e(G_1, G_2)^{f(τ) - y}
       = e((f(τ) - y)·G_1, G_2)
       = 右式

置換論證

複製約束問題

問題定義：

在電路中，我們需要證明不同位置的值相等。

例如：若電路有 a_1 = b_5 = c_3 的約束
      傳統方法需要額外的相等性驗證

PLONK 解法：
  將相等值編碼為置換的循環
  σ: (a_1) → (b_5) → (c_3) → (a_1)

關鍵洞察：
  若 f(σ(i)) = f(i) 對所有 i 成立
  則 f 的值在 σ 的每個循環內相同

Grand Product 累積器

定義：Grand Product 論證

設有兩個多項式 \(f(X)\) 和 \(g(X)\)，我們希望證明：

\(\prod_{i=0}^{n-1} f(\omega^i) = \prod_{i=0}^{n-1} g(\omega^i)\)

方法是構造累積器多項式 \(z(X)\) 滿足：

  • \(z(\omega^0) = 1\)（初始條件）
  • \(z(\omega \cdot X) = z(X) \cdot \frac{f(X)}{g(X)}\)（遞迴關係）

若 \(z(\omega^n) = z(\omega^0) = 1\)，則兩個乘積相等。

置換多項式定義：

設 k_1, k_2 為不同的 coset 偏移量，β, γ 為隨機挑戰。

f'(X) := (a(X) + β·X + γ)
       · (b(X) + β·k_1·X + γ)
       · (c(X) + β·k_2·X + γ)

g'(X) := (a(X) + β·S_{σ_1}(X) + γ)
       · (b(X) + β·S_{σ_2}(X) + γ)
       · (c(X) + β·S_{σ_3}(X) + γ)

其中 S_{σ_i}(X) 編碼置換：
  S_{σ_1}(ω^j) = 置換後 a_j 對應的索引位置
  S_{σ_2}(ω^j) = 置換後 b_j 對應的索引位置
  S_{σ_3}(ω^j) = 置換後 c_j 對應的索引位置

累積器約束：
  z(ω·X) · g'(X) = z(X) · f'(X)   (mod Z_H)
  L_0(X) · (z(X) - 1) = 0          (mod Z_H)

Coset 分離

為何需要 Coset：

問題：a, b, c 三個線變量的索引可能衝突
      例如 a_1 和 b_1 都有索引 1

解法：使用不同的 coset 區分三組變量
  a 的索引：{1, ω, ω², ..., ω^{n-1}}      = H
  b 的索引：{k_1, k_1ω, k_1ω², ...}       = k_1·H
  c 的索引：{k_2, k_2ω, k_2ω², ...}       = k_2·H

選擇 k_1, k_2：
  - k_1 和 k_2 是二次非剩餘（quadratic non-residue）
  - 保證三個 coset 互不相交
  - 常用：k_1 = 最小的二次非剩餘，k_2 = k_1 的二次非剩餘

通用設置

MPC 儀式

結構化參考字串（SRS）生成：

目標：生成 [τ^i]_1 和 [τ]_2，其中 τ 是未知的「有毒廢料」

單一 tau 儀式（Powers of Tau）：
  1. 第一位參與者選擇隨機 τ_1，輸出 ([τ_1^i]_1, [τ_1]_2)
  2. 第二位參與者選擇 τ_2，輸出 ([(τ_1·τ_2)^i]_1, ...)
  3. 繼續...

最終 τ = τ_1 · τ_2 · ... · τ_m

安全性：
  只要有一位參與者誠實地銷毀其 τ_i
  則 τ 對所有人都是未知的

實際部署：
  Zcash Powers of Tau：87 位參與者
  Perpetual Powers of Tau：持續進行

SRS 結構

定義：PLONK SRS

設最大支援度數為 \(d\)，PLONK 的 SRS 包含：

  • \(G_1\) 部分：\([1]_1, [\tau]_1, [\tau^2]_1, \ldots, [\tau^d]_1\)
  • \(G_2\) 部分：\([1]_2, [\tau]_2\)

總大小：\(d + 3\) 個群元素（\(d+1\) 個 \(G_1\) 元素，2 個 \(G_2\) 元素）

電路預處理

約束系統

PLONKish 算術化：

標準 PLONK 門（fan-in-2）：
  q_L · a + q_R · b + q_O · c + q_M · (a·b) + q_C = 0

選擇器配置範例：

加法門 (a + b = c)：
  q_L = 1, q_R = 1, q_O = -1, q_M = 0, q_C = 0
  驗證：1·a + 1·b + (-1)·c + 0·(a·b) + 0 = a + b - c = 0

乘法門 (a · b = c)：
  q_L = 0, q_R = 0, q_O = -1, q_M = 1, q_C = 0
  驗證：0 + 0 + (-1)·c + 1·(a·b) + 0 = a·b - c = 0

常數門 (a = 5)：
  q_L = 1, q_R = 0, q_O = 0, q_M = 0, q_C = -5
  驗證：1·a + 0 + 0 + 0 + (-5) = a - 5 = 0

公開輸入門 (a = PI_i)：
  q_L = 1, q_R = 0, q_O = 0, q_M = 0, q_C = 0
  另外加入：PI(ω^i) = -PI_i（負號抵消）

選擇器多項式

選擇器編碼：

設電路有 n 個約束（門），選擇器多項式定義為：

q_L(X)：在 ω^i 處值為第 i 個門的 q_L 係數
q_R(X)：在 ω^i 處值為第 i 個門的 q_R 係數
q_O(X)：在 ω^i 處值為第 i 個門的 q_O 係數
q_M(X)：在 ω^i 處值為第 i 個門的 q_M 係數
q_C(X)：在 ω^i 處值為第 i 個門的 q_C 係數

插值得到度數 < n 的多項式。

公開輸入多項式 PI(X)：
  PI(ω^i) = -x_i   若第 i 個門是公開輸入門
  PI(ω^i) = 0      否則

驗證金鑰

VK 組成（8 個 G_1 承諾 + 常數）：

[q_L]_1, [q_R]_1, [q_O]_1, [q_M]_1, [q_C]_1   // 選擇器
[S_{σ_1}]_1, [S_{σ_2}]_1, [S_{σ_3}]_1          // 置換

加上：
  n：電路大小
  ω：n 次單位根
  k_1, k_2：coset 偏移

驗證金鑰大小：O(1)（與電路大小無關）

證明者流程

五回合協議

回合 輸入 輸出 挑戰
1 見證 w [a]_1, [b]_1, [c]_1 β, γ
2 β, γ [z]_1 α
3 α [t_lo]_1, [t_mid]_1, [t_hi]_1 ζ
4 ζ ā, b̄, c̄, S̄_{σ_1}, S̄_{σ_2}, z̄_ω v
5 v [W_ζ]_1, [W_{ζω}]_1 -

回合 1：線多項式承諾

步驟：

1. 從見證構造線多項式：
   a(ω^i) = 第 i 個門的左輸入值
   b(ω^i) = 第 i 個門的右輸入值
   c(ω^i) = 第 i 個門的輸出值

2. 零知識盲化：
   選擇隨機 b_1, ..., b_6 ∈ F

   a'(X) = a(X) + (b_1·X + b_2)·Z_H(X)
   b'(X) = b(X) + (b_3·X + b_4)·Z_H(X)
   c'(X) = c(X) + (b_5·X + b_6)·Z_H(X)

   效果：在 H 外的點，多項式值被完全隨機化
         在 H 內，Z_H(X) = 0，值不變

3. 承諾：
   輸出 [a']_1, [b']_1, [c']_1

4. Fiat-Shamir：
   β = Hash(transcript, [a']_1, [b']_1, [c']_1)
   γ = Hash(transcript, β)

回合 2：累積器多項式

步驟：

1. 計算累積器值：
   z_0 = 1
   z_{i+1} = z_i · f'(ω^i) / g'(ω^i)

   其中：
   f'(ω^i) = (a(ω^i) + β·ω^i + γ)
           · (b(ω^i) + β·k_1·ω^i + γ)
           · (c(ω^i) + β·k_2·ω^i + γ)

   g'(ω^i) = (a(ω^i) + β·σ_1(ω^i) + γ)
           · (b(ω^i) + β·σ_2(ω^i) + γ)
           · (c(ω^i) + β·σ_3(ω^i) + γ)

2. 檢查：z_n 應該 = 1（驗證置換正確性）

3. 插值得到 z(X)，度數 < n

4. 零知識盲化：
   z'(X) = z(X) + (b_7·X² + b_8·X + b_9)·Z_H(X)

5. 承諾：輸出 [z']_1

6. Fiat-Shamir：α = Hash(transcript, [z']_1)

回合 3：商多項式

核心多項式恆等式：

Gate(X) + α·Perm(X) + α²·L_0(X)·(z(X) - 1) ≡ 0   (mod Z_H(X))

三部分拆解：

1. 門約束 Gate(X)：
   q_L(X)·a(X) + q_R(X)·b(X) + q_O(X)·c(X)
   + q_M(X)·a(X)·b(X) + q_C(X) + PI(X)

2. 置換約束 Perm(X)：
   z(X)·f'(X) - z(ω·X)·g'(X)

3. 邊界約束：
   L_0(X)·(z(X) - 1)

商多項式：
   t(X) = [Gate(X) + α·Perm(X) + α²·L_0(X)·(z(X) - 1)] / Z_H(X)

度數分析：
   註：表格中的 deg < n+3 考慮了盲化項 (b₁X² + b₂X + b₃)·Z_H(X)。
   以下分析使用未盲化的核心度數 deg < n；盲化項僅在 H 外影響值，
   不改變商多項式的核心結構。

   前提（未盲化核心）：deg(a), deg(b), deg(c) < n, deg(z) < n
   Gate(X)：deg < 2n（來自 q_M·a·b）
   Perm(X) = z(X)·f'(X) - z(ωX)·g'(X)
     - f'(X) 為三個 (< n) 項的乘積：deg(f') < 3n
     - z(X)·f'(X) 的度數 < n + 3n = 4n
   L_0(X)·(z(X) - 1)：deg < 2n

   分子最高次數由 Perm(X) 主導：< 4n
   除以 Z_H(X)（deg = n）後：deg(t) < 3n

分割為三部分（每部分度數 < n）：
   t(X) = t_lo(X) + X^n · t_mid(X) + X^{2n} · t_hi(X)

輸出：[t_lo]_1, [t_mid]_1, [t_hi]_1

Fiat-Shamir：ζ = Hash(transcript, [t_lo]_1, ...)

回合 4：點開啟

在隨機點 ζ 處評估多項式：

ā = a(ζ)           // 左線
b̄ = b(ζ)           // 右線
c̄ = c(ζ)           // 輸出線
S̄_{σ_1} = S_{σ_1}(ζ)   // 置換 1
S̄_{σ_2} = S_{σ_2}(ζ)   // 置換 2
z̄_ω = z(ζ·ω)       // 位移累積器

注意：z(ζ) 不直接提供，由驗證者透過線性化技術計算

Fiat-Shamir：v = Hash(transcript, ā, b̄, c̄, ...)

回合 5：開啟證明

線性化多項式 r(X)：

目的：將多項式在 ζ 處的評估轉換為承諾的線性組合

r(X) = ā·b̄·q_M(X) + ā·q_L(X) + b̄·q_R(X) + c̄·q_O(X) + q_C(X)
     + PI(ζ)
     + α·[(ā + β·ζ + γ)(b̄ + β·k_1·ζ + γ)(c̄ + β·k_2·ζ + γ)·z(X)
         - (ā + β·S̄_{σ_1} + γ)(b̄ + β·S̄_{σ_2} + γ)·β·z̄_ω·S_{σ_3}(X)]
     + α²·L_0(ζ)·z(X)
     - α²·L_0(ζ)
     - Z_H(ζ)·[t_lo(X) + ζ^n·t_mid(X) + ζ^{2n}·t_hi(X)]

在 ζ 處，r(ζ) 應該 = 0（核心恆等式）

開啟證明（在 ζ 處批次開啟）：
  W_ζ(X) = [r(X) + v·(a(X) - ā) + v²·(b(X) - b̄) + ...] / (X - ζ)

開啟證明（在 ζ·ω 處）：
  W_{ζω}(X) = (z(X) - z̄_ω) / (X - ζ·ω)

輸出：[W_ζ]_1, [W_{ζω}]_1

驗證者流程

驗證步驟

驗證者輸入：
  - 公開輸入 x = (x_1, ..., x_l)
  - 證明 π = ([a]_1, [b]_1, [c]_1, [z]_1,
              [t_lo]_1, [t_mid]_1, [t_hi]_1,
              ā, b̄, c̄, S̄_{σ_1}, S̄_{σ_2}, z̄_ω,
              [W_ζ]_1, [W_{ζω}]_1)
  - 驗證金鑰 VK

步驟 1：重建 Fiat-Shamir 挑戰
  β, γ, α, ζ, v, u = 依序 hash

步驟 2：計算輔助值
  Z_H(ζ) = ζ^n - 1
  L_0(ζ) = (ζ^n - 1) / (n·(ζ - 1))
  PI(ζ) = Σ x_i · L_i(ζ)

步驟 3：計算線性化承諾 [r]_1
  使用 VK 中的選擇器和置換承諾
  透過 MSM（Multi-Scalar Multiplication）計算

步驟 4：計算批次開啟值
  E = r(ζ) + v·ā + v²·b̄ + v³·c̄ + v⁴·S̄_{σ_1} + v⁵·S̄_{σ_2}
  [F]_1 = [r]_1 + v·[a]_1 + v²·[b]_1 + v³·[c]_1
        + v⁴·[S_{σ_1}]_1 + v⁵·[S_{σ_2}]_1

步驟 5：配對檢查
  e([W_ζ]_1 + u·[W_{ζω}]_1, [τ]_2)
  = e(ζ·[W_ζ]_1 + u·ζω·[W_{ζω}]_1 + [F]_1 - E·[1]_1
      + u·([z]_1 - z̄_ω·[1]_1), [1]_2)

  等價於兩個配對運算

擴展與變體

Plookup

定義：Plookup 查表論證[4]

Plookup 是 PLONK 的擴展，用於證明向量 \(f\) 的每個元素都出現在預定義的表格 \(T\) 中。核心思想是將查表轉換為置換論證：將 \(f\) 和 \(T\) 排序後，相鄰元素的差應該來自 \(T\) 的相鄰差集合。

Plookup 約束：

設 f = (f_1, ..., f_m) 是查表值
設 T = (t_1, ..., t_n) 是預定義表格

證明目標：∀i, f_i ∈ T

方法：
1. 構造排序向量 s = sort(f ⊎ T)  // ⊎ 為多重集合聯集（multiset union），保留重複元素
2. 證明 s 是 f ⊎ T 的排列
3. 證明 s 中相鄰差 (s_{i+1} - s_i) 都在 T 的相鄰差集合中

ZKML 應用：
- 激活函數：ReLU(x) 查表，x ∈ [-128, 127]
- 定點乘法：查預計算的乘積表
- 非線性：Sigmoid, GELU 查表近似

遞迴證明

PLONK 遞迴：

概念：在 PLONK 電路中驗證另一個 PLONK 證明

挑戰：
  - 需要在電路內計算配對
  - 配對成本：數百萬約束

解決方案：

1. 非原生域算術
   - 在 PLONK 約束中模擬非原生域運算
   - 成本：~1000 約束/域運算

2. 累積方案（Accumulation）
   - Halo 技術：延遲最終配對
   - 多個證明累積為一個
   - 最終僅需一次配對

3. Folding Scheme（Nova 系列）
   - 增量可驗證計算
   - 適合長鏈計算

安全性分析

安全屬性

PLONK 的安全保證：

1. 完備性（Completeness）
   誠實證明者總能生成有效證明
   證明：構造性，跟隨協議步驟

2. 知識健全性（Knowledge Soundness）
   若驗證通過，則存在提取器能取得見證
   假設：AGM + KoE
   安全等級：計算安全（非資訊論）

3. 零知識性（Zero-Knowledge）
   證明不洩露見證資訊
   技術：Z_H(X) 盲化因子

安全性歸約：
  PLONK 安全 ← KZG 安全 ← DL 困難假設
