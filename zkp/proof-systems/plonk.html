PLONK 概述

核心技術

算術化：PLONKish

PLONK 使用 PLONKish 算術化：

門約束：
  q_L · a + q_R · b + q_O · c + q_M · a·b + q_C = 0

其中：
  a, b, c = 線變量（wires）
  q_* = 選擇器多項式

特點：
  - 固定的門結構
  - 選擇器決定門類型
  - 支援自定義門

置換論證

PLONK 使用置換論證處理複製約束：

問題：證明不同位置的值相等
方案：將相等值編碼為置換的不動點

關鍵引理（Grand Product）：
  ∏(a_i + β·σ(i) + γ) = ∏(a_i + β·i + γ)
  當且僅當 a 符合置換 σ

多項式承諾

PLONK 使用 KZG 多項式承諾：

優點：
  - 常數大小承諾
  - 常數大小開啟證明
  - 支援批次驗證

限制：
  - 需要可信設置
  - 基於配對假設（非後量子）

ZKML 中的應用

為何 ZKML 選擇 PLONK

1. 自定義門
   - 可優化矩陣乘法
   - 可實現高效查表

2. 通用設置
   - 一次設置，多次使用
   - 不需為每個模型重新設置

3. 查表支援（Plookup）
   - 高效實現激活函數
   - 減少非線性約束
