預計涵蓋內容

單目標 Cost Function

基本形式：

cost(c) = prover_time(c) + λ₁ · 𝟙[acc(c) < threshold] + λ₂ · gas(c)

多目標最佳化

  • 只保留 acc ≥ 門檻的 config
  • 對剩餘 config 做 Pareto 分析
  • 找出 Pareto Frontier 上的最佳配置

權重選擇策略

  • 根據應用場景調整 λ 值
  • 區塊鏈應用：重視 gas
  • 即時推論：重視 prover_time
  • 資源受限：重視 RAM
